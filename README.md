##  Obstacle-Avoidance-Robot
An Arduino based Obstacle Avoidance Robot using ultrasonic sensors and an L298N motor driver 

##  Project Description

An Arduino-based robot that detects obstacles using an
ultrasonic sensor and automatically changes its direction
to avoid collisions.

##  Technologies Used

- Arduino UNO
- Ultrasonic Sensor
- Motor Driver
- DC Motors
- Embedded C

##  Components

- Arduino UNO
- HC-SR04 Ultrasonic Sensor
- L298N Motor Driver
- DC Motors
- Battery
- Arduino IDE Software

##  Working

The ultrasonic sensor continuously measures the distance
between the robot and nearby objects.

When an obstacle is detected within a specific distance,
the Arduino controls the motors and changes the robot's
direction.

##  Features

- Automatic obstacle detection
- Automatic direction control
- Real-time operation
